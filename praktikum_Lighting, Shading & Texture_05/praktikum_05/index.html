Bagian ini menjabarkan seluruh implementasi Challenge A hingga G secara mendalam, mencakup prinsip teoretis grafika komputer 3D, integrasi kode WebGL2 & GLSL ES 3.00, bedah kode langkah-demi-langkah, dan analisis visual responsifnya.

Challenge A — Image Texture Texture Mapping • Asynchronous Load • UV Inversion • CORS

1. Konsep Teoretis Grafika Komputer

Texture mapping memetakan ruang diskrit citra digital 2D (susunan texel) ke permukaan poligon 3D menggunakan sistem koordinat ternormalisasi UV (u, v) ∈ [0, 1]. Pada pipeline WebGL2, pemuatan citra bitmap eksternal menghadapi sejumlah tantangan grafis:

  • Pembalikan Sumbu Vertikal (Y-axis Inversion): Sistem koordinat WebGL meletakkan titik origin (0, 0) pada sudut kiri-bawah dengan arah sumbu vertikal +Y ke atas. Sebaliknya, standar citra web (DOM Image, Canvas, SVG, PNG) menempatkan titik origin (0, 0) pada sudut kiri-atas dengan +Y ke bawah. Tanpa operasi unpack flip, tekstur akan terproyeksikan terbalik (upside-down).
  • Kebijakan Keamanan CORS (Cross-Origin Resource Sharing): Mengunduh citra dari domain eksternal memerlukan atribut crossOrigin = "anonymous" agar context WebGL tidak ditandai sebagai tainted (terkontaminasi), yang dapat menyebabkan penolakan eksekusi gl.texImage2D.
  • Penanganan Asinkron via 1x1 Placeholder: Citra diunduh melalui protokol HTTP secara non-blocking. Untuk mencegah webgl merender tekstur null/kosong saat frame awal digambar, dialokasikan tekstur placeholder sementara berukuran 1x1 piksel RGBA.

2. Implementasi Kode

// 1. Alokasi Objek Tekstur dan Penyiapan Placeholder 1x1 piksel sementara
const imageTexture = gl.createTexture();
gl.bindTexture(gl.TEXTURE_2D, imageTexture);
gl.texImage2D(
  gl.TEXTURE_2D,
  0,                  // Level Mipmap dasar (level 0)
  gl.RGBA,           // Format internal WebGL
  1, 1, 0,           // Lebar 1px, Tinggi 1px, Border 0
  gl.RGBA,           // Format data piksel sumber
  gl.UNSIGNED_BYTE,  // Tipe data per komponen (8-bit per channel)
  new Uint8Array([40, 90, 150, 255]) // Warna biru fallback sementara
);

// 2. Pemuatan Asinkron Gambar Eksternal dengan Penanganan CORS & UV Flip
const image = new Image();
image.crossOrigin = "anonymous"; // Mencegah pemblokiran keamanan CORS
image.onload = () => {
  gl.bindTexture(gl.TEXTURE_2D, imageTexture);
  gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true); // Balik orientasi Y agar pas dengan UV WebGL
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, image);
  updateTextureState(); // Terapkan konfigurasi filter dan wrap yang sedang aktif
};
image.src = "https://darlis-its.github.io/materi-grafika-komputer/praktikum/output/pert05/texture.svg";

// 3. Ekstraksi Warna di Fragment Shader (GLSL ES 3.00)
vec3 baseColor = u_useTexture ? texture(u_texture, v_uv).rgb : vec3(0.35, 0.78, 1.0);

3. Bedah Kode Baris per Baris

  • gl.createTexture(): Meminta GPU mengalokasikan handle objek tekstur baru pada memori VRAM.
  • gl.bindTexture(gl.TEXTURE_2D, imageTexture): Mengaitkan target tekstur 2D aktif ke objek tekstur tersebut.
  • gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true): Menginstruksikan modul unpacker membalik urutan baris memori vertikal piksel sehingga koordinat UV (0,0) WebGL di kiri-bawah selaras dengan citra asli.
  • gl.texImage2D(...): Mentransfer data larik piksel ke GPU dengan internal format 32-bit RGBA (8-bit tiap kanal warna).
  • texture(u_texture, v_uv): Fungsi GLSL yang melakukan sampling texel terinterpolasi pada poligon.

4. Dampak Visual & Hasil Observasi

Ketika dropdown Texture Source diubah ke Image (texture.svg), motif logo SVG tampil tegak, tajam, dan presisi di seluruh sisi kubus, bola, torus, dan torus knot. Tidak ada kedipan frame kosong saat startup berkat adanya buffer placeholder 1x1 piksel.

Challenge B — Ambient Control Phong Reflection • Uniform 1f • Global Illumination Approximation

1. Konsep Teoretis Grafika Komputer

Pada model refleksi Phong, pencahayaan total dirumuskan sebagai superposisi tiga komponen aditif: I = I_ambient + I_diffuse + I_specular.

Komponen Ambient Light mensimulasikan pemantulan cahaya tidak langsung (indirect/scattered light) dari lingkungan sekitar. Tanpa adanya ambient light, setiap sisi objek poligon yang membelakangi vektor datangnya cahaya akan bernilai hitam pekat mutlak (RGB = 0, 0, 0), menciptakan kontras tak wajar. Formulasi ambient: I_ambient = k_a × I_light, di mana k_a adalah konstanta kekuatan ambien (u_ambientStrength) dan I_light adalah warna sumber cahaya.

2. Implementasi Kode

// 1. Event Listener Input Slider di main.js
document.querySelector("#ambientControl").oninput = (e) => {
  state.ambient = Number(e.target.value);
  document.querySelector("#ambientValue").textContent = state.ambient.toFixed(2);
};

// 2. Shortcut Keyboard (Tombol A: Naik, Tombol Z: Turun)
if (key === "a") { state.ambient = Math.min(1.0, state.ambient + 0.05); }
if (key === "z") { state.ambient = Math.max(0.0, state.ambient - 0.05); }

// 3. Pengiriman Uniform ke Fragment Shader (di fungsi draw)
gl.uniform1f(locations.ambient, state.ambient);

// 4. Komputasi Iluminasi di Fragment Shader
uniform float u_ambientStrength;
uniform vec3 u_lightColor;
uniform bool u_useAmbient;

vec3 ambient = u_useAmbient ? u_ambientStrength * u_lightColor : vec3(0.0);
outColor = vec4(baseColor * (ambient + diffuse) + specular, 1.0);

3. Bedah Kode Baris per Baris

  • document.querySelector("#ambientControl").oninput: Menangkap perubahan slider realtime dari nilai 0.00 hingga 1.00.
  • gl.uniform1f(locations.ambient, state.ambient): Mengunggah nilai skalar float 32-bit ke variabel seragam GPU pada setiap siklus frame.
  • u_useAmbient ? u_ambientStrength * u_lightColor : vec3(0.0): Percabangan dinamis pada shader untuk menonaktifkan atau mengalikan intensitas warna cahaya dengan koefisien ambient.
  • baseColor * (ambient + diffuse): Komponen ambien memodulasi warna dasar tekstur (albedo) sehingga rona warna permukaan tetap terlihat di area bayangan.

4. Dampak Visual & Hasil Observasi

  • Nilai 0.00: Daerah bayangan di belakang objek menjadi hitam total, menghasilkan kontras bayangan tajam khas ruang hampa udara luar angkasa.
  • Nilai 0.18 (Default): Menghasilkan proporsi bayangan yang natural, di mana lekukan tekstur di sisi gelap tetap terbaca lembut.
  • Nilai 1.00: Seluruh objek teriluminasi penuh secara seragam, menghilangkan kesan kedalaman dan dimensi bayangan 3D.

Challenge C — Camera Control View Matrix • LookAt • Specular Halfway Vector • View-Dependent Lighting

1. Konsep Teoretis Grafika Komputer

Kamera virtual 3D didefinisikan menggunakan View Matrix yang mentransformasikan koordinat dunia (World Space) ke koordinat mata pengamat (View Space) melalui fungsi lookAt(eye, target, up).

Pergeseran posisi kamera tidak hanya mengubah sudut pandang dan paralaks objek, tetapi juga berdampak langsung pada perhitungan pantulan mengkilap Specular Blinn-Phong:

viewDirection = normalize(cameraPosition - worldPosition)
halfVector = normalize(lightDirection + viewDirection)
I_specular = pow(max(dot(normal, halfVector), 0.0), shininess) × I_light

Karena viewDirection bergantung langsung pada letak kamera, kilau pantulan putih (specular highlight) akan bergeser melintasi kontur permukaan objek mengikuti perpindahan mata pengamat (bersifat view-dependent).

2. Implementasi Kode

// 1. Pembaruan Koordinat Kamera Berbasis Selisih Waktu di updateCamera()
function updateCamera(deltaTime) {
  const speed = 1.8 * deltaTime; // Gerakan mulus independen dari variasi refresh rate
  
  if (state.keys.q) state.camera.position[0] -= speed; // Geser kamera ke kiri (-X)
  if (state.keys.e) state.camera.position[0] += speed; // Geser kamera ke kanan (+X)
  
  // Orbit Kamera Otomatis
  if (state.cameraOrbit) {
    state.camera.position[0] = Math.sin(state.time * 0.45) * 5;
    state.camera.position[2] = Math.cos(state.time * 0.45) * 5;
  }
}

// 2. Pembuatan Matriks Pandangan dan Binding Uniform
const view = lookAt(state.camera.position, state.camera.target, state.camera.up);
gl.uniformMatrix4fv(locations.view, false, view);
gl.uniform3fv(locations.cameraPosition, state.camera.position);

// 3. Fragment Shader: Komputasi Vektor Pandang dan Specular Highlight
vec3 viewDirection = normalize(u_cameraPosition - v_worldPosition);
vec3 halfVector = normalize(lightDirection + viewDirection);
float specularAmount = pow(max(dot(normal, halfVector), 0.0), u_shininess);

3. Bedah Kode Baris per Baris

  • const speed = 1.8 * deltaTime: Menjamin laju perpindahan kamera tetap stabil dan konsisten pada layar 60Hz, 120Hz, maupun 144Hz.
  • state.keys.q / state.keys.e: Membaca input penekanan tombol kontinu dari keyboard untuk translasi horizontal sumbu X.
  • gl.uniform3fv(locations.cameraPosition, ...): Memasok koordinat aktual kamera ke fragment shader untuk evaluasi vektor arah pandang tiap fragmen poligon.
  • normalize(lightDirection + viewDirection): Mengkalkulasi halfway vector Blinn-Phong yang mengoptimalkan komputasi pantulan specular dibanding Phong klasik.

4. Dampak Visual & Hasil Observasi

Saat tombol Q atau E ditekan, sudut pandang berpindah secara halus. Terlihat jelas bintik pantulan kilau putih (specular highlight) pada permukaan melengkung bola atau torus knot bergeser secara realistis mengikuti perubahan sudut pandang kamera pengamat.

Challenge D — Non-Uniform Scale Mode Non-Uniform Scale • Normal Matrix • Inverse-Transpose • Orthogonality Preservation

1. Konsep Teoretis Grafika Komputer

Pada penskalaan seragam (uniform scale, Sx = Sy = Sz), proporsi geometris tetap terjaga. Namun, pada Non-Uniform Scale (misal Sx ≠ Sy), objek diregangkan atau dipipihkan secara asimetris.

Permasalahan Vektor Normal: Vektor normal N wajib selalu tegak lurus (ortogonal, 90°) terhadap permukaan poligon. Jika vektor normal dikalikan langsung dengan Model Matrix biasa (M × N), deformasi asimetris akan memiringkan arah vektor normal sehingga tidak lagi ortogonal terhadap permukaan baru. Akibatnya, kalkulasi diffuse (N • L) dan specular (N • H) menjadi cacat dengan bayangan yang miring tidak wajar.

Solusi Matematis (Normal Matrix): Untuk mempertahankan ortogonalitas, vektor normal harus ditransformasikan menggunakan Transpose dari Invers sub-matriks 3×3 model: M_normal = (M_3x3^-1)^T.

2. Implementasi Kode

// 1. Algoritma Perhitungan Matriks Inverse-Transpose 3x3 di main.js
function normalMatrixFromMat4(m) {
  const a00 = m[0], a01 = m[4], a02 = m[8],
        a10 = m[1], a11 = m[5], a12 = m[9],
        a20 = m[2], a21 = m[6], a22 = m[10];
  const b01 = a22 * a11 - a12 * a21,
        b11 = -a22 * a10 + a12 * a20,
        b21 = a21 * a10 - a11 * a20;
  const determinant = a00 * b01 + a01 * b11 + a02 * b21 || 1;
  return new Float32Array([
    b01 / determinant,
    (-a22 * a01 + a02 * a21) / determinant,
    (a12 * a01 - a02 * a11) / determinant,
    b11 / determinant,
    (a22 * a00 - a02 * a20) / determinant,
    (-a12 * a00 + a02 * a10) / determinant,
    b21 / determinant,
    (-a21 * a00 + a01 * a20) / determinant,
    (a11 * a00 - a01 * a10) / determinant,
  ]);
}

// 2. Pengiriman ke Vertex Shader (di fungsi draw)
gl.uniformMatrix3fv(locations.normalMatrix, false, normalMatrixFromMat4(model));

// 3. Koreksi Vektor Normal di Vertex Shader (GLSL ES 3.00)
uniform mat3 u_normalMatrix;
in vec3 a_normal;
out vec3 v_normal;

void main() {
  ...
  v_normal = u_normalMatrix * a_normal; // Vektor normal tetap tegak lurus
  ...
}

3. Bedah Kode Baris per Baris

  • scale(...state.scale): Mengalikan matriks model dengan faktor skala independen sumbu X, Y, dan Z dari slider kontrol.
  • normalMatrixFromMat4(m): Menghitung determinan dan kofaktor 3x3 model, menginverskan matriks lalu mentransposisikannya (menukar baris dan kolom). Translasi baris ke-4 sengaja diabaikan karena normal adalah vektor arah murni tanpa posisi.
  • gl.uniformMatrix3fv(...): Mentransfer matriks 3x3 hasil invers-transpose ke variabel u_normalMatrix GPU.
  • normalize(v_normal) di Fragment Shader: Menormalkan kembali panjang vektor normal menjadi 1.0 setelah diinterpolasi oleh rasterizer poligon.

4. Dampak Visual & Hasil Observasi

Bahkan ketika objek kubus dipipihkan secara ekstrem menjadi pelat tipis (misal Scale Y = 0.2, Scale X = 2.5), bayangan shading diffuse dan kilau specular pada permukaan atas tetap terdistribusi rata dan tegak lurus secara sempurna tanpa pembiasan cahaya yang cacat.

Challenge E — Light Orbit Trigonometric Parametric Path • Circular Orbit • Dynamic Shadow Terminator

1. Konsep Teoretis Grafika Komputer

Menggerakkan sumber cahaya dalam lintasan melingkar 360° memvalidasi keakuratan respon material poligon terhadap pergerakan vektor cahaya datang. Lintasan melingkar pada bidang horizontal XZ dimodelkan secara analitis menggunakan persamaan parametrik trigonometri lingkaran:

X(t) = R × sin(ω × t)
Z(t) = R × cos(ω × t)
Y(t) = konstan (ketinggian sumber cahaya, misal Y = 2.0)

Radius R = 3.0 unit menjamin sumber cahaya berada di luar radius batas geometri objek sehingga bayangan terminator berputar mulus mengitari objek.

2. Implementasi Kode

// 1. Komputasi Koordinat Melingkar di updateCamera()
if (state.lightOrbit) {
  state.light[0] = Math.sin(state.time) * 3; // Posisi melingkar sumbu X
  state.light[2] = Math.cos(state.time) * 3; // Posisi melingkar sumbu Z
}

// 2. Tombol Toggle Orbit (UI & Keyboard 'L')
document.querySelector("#lightOrbitButton").onclick = () => {
  state.lightOrbit = !state.lightOrbit;
};
if (key === "l") state.lightOrbit = !state.lightOrbit;

// 3. Fragment Shader: Evaluasi Vektor Cahaya Realtime
vec3 lightDirection = normalize(u_lightPosition - v_worldPosition);
float diffuseAmount = max(dot(normal, lightDirection), 0.0);

3. Bedah Kode Baris per Baris

  • Math.sin(state.time) * 3 & Math.cos(state.time) * 3: Menghasilkan pasangan koordinat sinusoidal berfase 90° yang membentuk kurva orbit lingkaran berkesinambungan.
  • state.time += dt: Variabel waktu akumulatif berbasis selisih waktu presisi tinggi dari requestAnimationFrame.
  • gl.uniform3fv(locations.lightPosition, state.light): Memperbarui posisi koordinat lampu ke GPU setiap kali frame baru digambar.
  • normalize(u_lightPosition - v_worldPosition): Menghitung ulang vektor datang cahaya θ terhadap normal untuk setiap fragmen piksel poligon secara dinamis.

4. Dampak Visual & Hasil Observasi

Sumber cahaya berputar melingkari objek secara konsisten. Garis batas terang-gelap (shadow terminator) dan kilapan highlight specular menyapu permukaan kubus, bola, torus, dan torus knot secara berkelanjutan. Kartu HUD indikator LIGHT menampilkan perubahan koordinat numerik (X, Y, Z) secara realtime.

Challenge F — Lighting Components Toggle Additive Decomposition • Boolean Uniforms • Diagnostic Material Inspection

1. Konsep Teoretis Grafika Komputer

Phong Reflection Model bersifat aditif murni: C_final = C_base × (I_ambient + I_diffuse) + I_specular.

Kemampuan untuk mengisolasi setiap komponen pencahayaan secara independen sangat esensial untuk keperluan inspeksi teknis material dan kalibrasi shader:

  • Ambient Murni: Menguji kecerahan minimum tanpa pengaruh sudut kemiringan permukaan terhadap sumber sinar.
  • Diffuse Murni (Lambertian): Menguji kurvatur permukaan 3D dan transisi kehalusan bayangan poligon.
  • Specular Murni: Menguji konsentrasi pantulan kilau material dan keakuratan sudut pengamatan kamera.

2. Implementasi Kode

// 1. State Boolean Komponen & Event Listener Checkbox di main.js
state.components = { ambient: true, diffuse: true, specular: true };

["ambient", "diffuse", "specular"].forEach((name) =>
  (document.querySelector(`#${name}Toggle`).onchange = (e) => {
    state.components[name] = e.target.checked;
  })
);

// Shortcut Keyboard: Tombol '1' (Ambient), '2' (Diffuse), '3' (Specular)
if (key === "1") toggleComponent("ambient");
if (key === "2") toggleComponent("diffuse");
if (key === "3") toggleComponent("specular");

// 2. Mengirimkan Boolean Flag ke Uniform WebGL (di fungsi draw)
gl.uniform1i(locations.useAmbient, state.components.ambient);
gl.uniform1i(locations.useDiffuse, state.components.diffuse);
gl.uniform1i(locations.useSpecular, state.components.specular);

// 3. Dekomposisi Aditif di Fragment Shader (GLSL ES 3.00)
uniform bool u_useAmbient;
uniform bool u_useDiffuse;
uniform bool u_useSpecular;

vec3 ambient  = u_useAmbient  ? u_ambientStrength * u_lightColor : vec3(0.0);
vec3 diffuse  = u_useDiffuse  ? diffuseAmount * u_lightColor     : vec3(0.0);
vec3 specular = u_useSpecular ? specularAmount * u_lightColor    : vec3(0.0);

outColor = vec4(baseColor * (ambient + diffuse) + specular, 1.0);

3. Bedah Kode Baris per Baris

  • state.components[name] = e.target.checked: Menyimpan status aktif masing-masing komponen pencahayaan ke state aplikasi.
  • gl.uniform1i(locations.useDiffuse, ...): Pada WebGL2 GLSL ES 3.00, seragam bertipe bool di-passing sebagai integer (1 = true, 0 = false) menggunakan fungsi gl.uniform1i.
  • u_useDiffuse ? diffuseAmount * u_lightColor : vec3(0.0): Operator ternary shader menihilkan kontribusi warna komponen terkait jika flag bernilai false tanpa menghentikan pipeline rendering.

4. Dampak Visual & Hasil Observasi

Challenge G — Mipmap Filtering Texture Minification • Trilinear Filtering • Moire Suppression • GPU Pyramid

1. Konsep Teoretis Grafika Komputer

Ketika objek 3D bertekstur berada pada posisi jauh dari kamera atau dilihat pada sudut miring (oblique angle), area proyeksi satu piksel layar mencakup banyak texel citra asli (Texture Minification).

  • Filter Nearest: Mengambil satu texel terdekat, menimbulkan artefak bergerigi kasar (pixelation) dan getaran piksel tajam (flickering/shimmering) saat kamera bergerak.
  • Filter Linear: Merata-ratakan 4 texel terdekat pada resolusi penuh, namun tetap rentan menghasilkan pola interferensi Moire pada jarak ekstrem.
  • Solusi Mipmap (Hierarki Piramida Citra): Teknik Mipmapping membuat deretan salinan tekstur prasetel yang resolusinya diturunkan setengahnya secara eksponensial (128×128 → 64×64 → 32×32 → ... → 1×1).

Dengan filter LINEAR_MIPMAP_LINEAR (Trilinear Filtering), GPU melakukan interpolasi bilinear pada dua level piramida terdekat, lalu menginterpolasi linear hasil kedua level tersebut berdasarkan laju turunan koordinat UV layar (dFdx, dFdy).

2. Implementasi Kode

// 1. Pengaturan Filter Tekstur & Generasi Mipmap di updateTextureState()
function updateTextureState() {
  const texture = state.textureSource === "image" ? imageTexture : checkerTexture;
  gl.bindTexture(gl.TEXTURE_2D, texture);

  const filter = state.filter === "nearest" ? gl.NEAREST : gl.LINEAR;
  
  // Konfigurasi Minification Filter (Pengecilan)
  gl.texParameteri(
    gl.TEXTURE_2D,
    gl.TEXTURE_MIN_FILTER,
    state.filter === "mipmap" ? gl.LINEAR_MIPMAP_LINEAR : filter
  );

  // Konfigurasi Magnification Filter (Pembesaran)
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, filter);

  // Konfigurasi Wrapping Mode Sumbu S dan T
  const wrapMode = state.wrap === "repeat" ? gl.REPEAT : gl.CLAMP_TO_EDGE;
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, wrapMode);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, wrapMode);

  // Generasi otomatis seluruh hierarki Mipmap oleh GPU
  if (state.filter === "mipmap") {
    gl.generateMipmap(gl.TEXTURE_2D);
  }
}

3. Bedah Kode Baris per Baris

  • gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR_MIPMAP_LINEAR): Mengaktifkan mode penyaringan trilinear saat tekstur mengalami pengecilan (minification).
  • gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, filter): Mipmap tidak berlaku pada pembesaran (magnification), sehingga filter dibatasi pada gl.LINEAR atau gl.NEAREST.
  • gl.generateMipmap(gl.TEXTURE_2D): Memerintahkan driver WebGL2/GPU untuk mengompilasi dan mengalokasikan seluruh rantai piramida mipmap dari level 0 ke level 1x1.
  • Dukungan Native NPOT: Pada WebGL2, tekstur dengan dimensi bukan kelipatan pangkat dua (Non-Power of Two) didukung penuh secara native untuk mipmap dan repeat wrap.

4. Dampak Visual & Hasil Observasi

  • Nearest: Garis kotak-kotak checkerboard tampak patah-patah bergerigi kasar dan berkedip saat kubus berotasi.
  • Linear: Tampilan tampak lebih baik dari dekat, tetapi pola ubin di kejauhan memunculkan garis distorsi moire yang mengganggu.
  • Mipmap (Trilinear): Seluruh artefak getaran dan distorsi moire tereliminasi total. Tekstur di kejauhan tampak halus, bersih, dan stabil, mencerminkan kualitas grafika 3D profesional.
