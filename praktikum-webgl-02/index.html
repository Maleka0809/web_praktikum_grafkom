Penjelasan Pemenuhan Requirement & Challenge

🎯 Pemenuhan Kriteria Dasar (Requirements)

  • Minimal 3 Primitive & 2 Draw Mode: Terdapat 4 objek dasar (Segitiga, Persegi, Segi Lima Garis, Diamond). Masing-masing menggunakan draw mode berbeda: gl.TRIANGLES, gl.TRIANGLE_STRIP, gl.LINE_LOOP, dan gl.TRIANGLE_FAN.
  • Vertex Color & Minimal 3 Warna: Array baseVertices menampung 5 nilai per titik (X, Y, R, G, B) dengan variasi warna lebih dari 3 (Merah, Hijau, Biru, Kuning, dll).
  • Minimal Satu Object Bergerak: Terdapat 4 primitif yang terus bergerak bebas dan memantul ketika mengenai batas kanvas layar.
  • Interaksi & Loop: Interaksi keyboard (W, S, P, R, C, Arah) dan Mouse (klik). Animasi berjalan mulus melalui requestAnimationFrame.
  • Lainnya: Background biru-gelap terpisah, transformasi (translasi dan skala) dihitung menggunakan matematika vertex dasar di fungsi updateBufferData(), kode dirapihkan tanpa duplikasi fungsi berlebih.

🚀 Penjelasan Challenge (A - F)

  • A. Primitive Selector: Terdapat Dropdown di panel kontrol untuk mengganti mode. Ketika diganti, mainDrawMode di script akan menyesuaikan dan diterapkan di drawArrays.
  • B. Color Control: Tombol warna (termasuk tombol ? untuk warna random). Ketika diklik, akan mengubah nilai RGB dari bentuk pertama di memori baseVertices.
  • C. Spawn Primitive: Ketika layar diklik, posisi pixel mouse dikonversi menjadi kordinat NDC, lalu script menambahkan objek (3 vertex baru) tepat di posisi kursor klik.
  • D. Multiple Moving Objects: Ke-4 objek bergerak dengan arah & kecepatan mandiri. Logika pantulan dikalkulasi pada fungsi updateBouncing() memantau batas X dan Y (-1.0 hingga 1.0).
  • E. Procedural Pattern: Terdapat garis grid di background. Data titiknya di-generate otomatis dengan perulangan for loop di awal JavaScript.
  • F. Simple HUD: Data indikator seperti angka FPS, jumlah objek (spawn), kecepatan, dan kordinat kursor NDC disuntikkan ke teks HTML murni secara real-time via innerText agar tidak membebani WebGL rendering.
