Penjelasan Pemenuhan Requirement & Challenge

🎯 Pemenuhan Kriteria Dasar (Requirements)

1. Minimal 3 Primitive & 2 Draw Mode

Terdapat 4 objek dasar (Segitiga, Persegi, Segi Lima Garis, Diamond). Masing-masing menggunakan draw mode berbeda: gl.TRIANGLES, gl.TRIANGLE_STRIP, gl.LINE_LOOP, dan gl.TRIANGLE_FAN.

gl.drawArrays(mainDrawMode, offset, 3); // Segitiga
gl.drawArrays(gl.TRIANGLE_STRIP, offset, 4); // Persegi
gl.drawArrays(gl.LINE_LOOP, offset, 5); // Segi lima
gl.drawArrays(gl.TRIANGLE_FAN, offset, 4); // Diamond

2. Vertex Color & Minimal 3 Warna

Array baseVertices menampung 5 nilai per titik (X, Y, R, G, B) dengan variasi warna lebih dari 3 (Merah, Hijau, Biru, Kuning, dll).

-0.15, -0.15, 1.0, 0.0, 0.0, // Merah
 0.15, -0.15, 0.0, 1.0, 0.0, // Hijau
 0.00,  0.15, 0.0, 0.0, 1.0, // Biru

3. Minimal Satu Object Bergerak

Terdapat 4 primitif yang terus bergerak bebas dan memantul ketika mengenai batas kanvas layar.

const movingObjects = [
    { posX: 0, posY: 0, vx: 0.005, vy: 0.003 },
    { posX: 0, posY: 0, vx: -0.004, vy: 0.006 },
    // ...
];

4. Interaksi & Loop

Interaksi keyboard (W, S, P, R, C, Arah) dan Mouse (klik). Animasi berjalan mulus melalui requestAnimationFrame.

window.addEventListener("keydown", (event) => { ... });
requestAnimationFrame(render);

5. Kriteria Lainnya

Background biru-gelap terpisah, transformasi (translasi dan skala) dihitung menggunakan matematika vertex dasar di fungsi updateBufferData(), kode dirapihkan tanpa duplikasi fungsi berlebih.

gl.clearColor(0.03, 0.05, 0.10, 1.0); // Background
// Transformasi Skala & Translasi manual di Javascript
const lx = (baseVertices[offset] - cx) * scale;
const ly = (baseVertices[offset + 1] - cy) * scale;
updatedVertices[offset] = cx + lx + obj.posX + offsetX;

🚀 Penjelasan Challenge (A - F)

A. Primitive Selector

Terdapat Dropdown di panel kontrol untuk mengganti mode. Ketika diganti, mainDrawMode di script akan menyesuaikan dan diterapkan di drawArrays.

document.getElementById("primitiveSelector").addEventListener("change", (e) => {
    mainDrawMode = gl[e.target.value];
});

B. Color Control

Tombol warna (termasuk tombol ? untuk warna random). Ketika diklik, akan mengubah nilai RGB dari bentuk pertama di memori baseVertices.

function setMainColor(r, g, b) {
    for(let i = 0; i < 3; i++) {
        baseVertices[i*5 + 2] = r;
        baseVertices[i*5 + 3] = g;
        baseVertices[i*5 + 4] = b;
    }
}

C. Spawn Primitive

Ketika layar diklik, posisi pixel mouse dikonversi menjadi kordinat NDC, lalu script menambahkan objek (3 vertex baru) tepat di posisi kursor klik.

canvas.addEventListener('click', () => {
    let cx = mouseNDC.x, cy = mouseNDC.y;
    spawnedVertices.push(cx - s, cy - s, r, g, b, ...);
});

D. Multiple Moving Objects

Ke-4 objek bergerak dengan arah & kecepatan mandiri. Logika pantulan dikalkulasi pada fungsi updateBouncing() memantau batas X dan Y (-1.0 hingga 1.0).

if (minX < -1.0) { obj.posX += (-1.0 - minX); obj.vx = Math.abs(obj.vx); }
if (maxX > 1.0) { obj.posX -= (maxX - 1.0); obj.vx = -Math.abs(obj.vx); }

E. Procedural Pattern

Terdapat garis grid di background. Data titiknya di-generate otomatis dengan perulangan for loop di awal JavaScript.

for (let i = -1.0; i <= 1.0; i += 0.1) {
    gridVertices.push(i, -1.0, 0.2, 0.2, 0.2,  i, 1.0, 0.2, 0.2, 0.2); // vertikal
    gridVertices.push(-1.0, i, 0.2, 0.2, 0.2,  1.0, i, 0.2, 0.2, 0.2); // horizontal
}

F. Simple HUD

Data indikator seperti angka FPS, jumlah objek (spawn), kecepatan, dan kordinat kursor NDC disuntikkan ke teks HTML murni secara real-time via innerText agar tidak membebani WebGL rendering.

document.getElementById("fpsDisplay").innerText = currentFps;
document.getElementById('mouseNdcDisplay').innerText = `${mouseNDC.x.toFixed(2)}, ${mouseNDC.y.toFixed(2)}`;
