PRAKTIKUM 01

Interactive Canvas

Eksperimen objek 2D, animasi, transformasi, mouse, keyboard, State-Based, dan Event-Based.

SOAL PRAKTIKUM

Penjelasan Pseudocode & Kode

Setiap topik dijelaskan dengan pseudocode (bahasa sederhana) lalu kode nyata dari file JS.

HTML Canvas adalah elemen HTML yang berfungsi sebagai papan gambar digital. Canvas tidak bisa menggambar sendiri — semua dikerjakan JavaScript via Canvas 2D API.

📦
KONSEP DASAR
Tag <canvas> dan Cara Membuatnya
Tag <canvas> hanya menyediakan area gambar kosong. Atribut width dan height menentukan ukuran piksel. Untuk menggambar, kita ambil konteks (ctx) menggunakan JavaScript. Konteks ini berisi semua perintah menggambar.
📋 Pseudocode
LANGKAH 1: Buat elemen canvas di HTML
  Tentukan id, lebar (width), tinggi (height)

LANGKAH 2: Di JavaScript, ambil referensi canvas
  canvas = document.getElementById("id-canvas")

LANGKAH 3: Minta konteks 2D dari canvas
  ctx = canvas.getContext("2d")

SEKARANG ctx siap dipakai untuk menggambar:
  ctx.fillRect(...)    ← gambar kotak berisi warna
  ctx.arc(...)         ← gambar lingkaran
  ctx.lineTo(...)      ← gambar garis
  ctx.stroke()         ← cetak garis ke canvas
💻 Kode HTML + JavaScript (state-based.js)
<!-- Di file HTML: buat elemen canvas -->
<canvas
  id="graphicsCanvas"
  width=960
  height=600>
</canvas>

// Di JavaScript: ambil canvas dan konteks
const stateCanvas =
  document.getElementById("graphicsCanvas");

const stateCtx =
  stateCanvas.getContext("2d");

// Simpan ukuran agar mudah dipakai
const SW = stateCanvas.width;  // = 960
const SH = stateCanvas.height; // = 600
💡 getContext("2d") mengembalikan objek CanvasRenderingContext2D yang berisi semua perintah menggambar. Simpan ke variabel ctx agar tidak perlu menulis ulang terus.
📐
SISTEM KOORDINAT
Titik (0,0) Ada di Pojok Kiri Atas
Berbeda dengan matematika biasa, di Canvas titik awal (0,0) ada di pojok kiri atas. Semakin ke kanan, nilai X bertambah. Semakin ke bawah, nilai Y bertambah. Pahami ini agar objek digambar di posisi yang tepat.
📋 Pseudocode — Sistem Koordinat
  (0,0) ———————————————→  X+ (ke kanan)
    |
    |   (80, 90)   ← 80 dari kiri, 90 dari atas
    |
    |   (700, 135) ← 700 dari kiri, 135 dari atas
    |
   Y+ (ke bawah)

Canvas 960 x 600:
  Pojok kiri atas   = (0, 0)
  Pojok kanan atas  = (960, 0)
  Pojok kiri bawah  = (0, 600)
  Pojok kanan bawah = (960, 600)
  Tengah canvas     = (480, 300)
💻 Kode — Contoh Posisi
// SW = 960, SH = 600
const SW = stateCanvas.width;
const SH = stateCanvas.height;

// Gambar di pojok kiri atas
ctx.fillRect(0, 0, 100, 50);

// Gambar di tengah canvas
ctx.fillRect(
  SW/2 - 50,  // = 430
  SH/2 - 25,  // = 275
  100, 50
);

// Kotak biru di (80,90) ukuran 170x105
ctx.fillStyle = "#3b82f6";
ctx.fillRect(80, 90, 170, 105);
💡 Selalu simpan canvas.width dan canvas.height ke variabel (SW, SH) agar mudah dipakai saat menghitung batas dan posisi tengah canvas.
📚
URUTAN MENGGAMBAR
Style Dulu, Gambar Kemudian — Aturan Wajib
Aturan penting Canvas: atur style/warna DULU, baru gambar. Untuk rectangle, cukup satu fungsi. Untuk bentuk lain (garis, lingkaran, segitiga), gunakan path: beginPath → definisikan bentuk → fill/stroke.
📋 Pseudocode — Dua Cara Menggambar
CARA 1 — Rectangle (langsung, tanpa path):
  SET fillStyle = warna
  fillRect(x, y, lebar, tinggi)
  → Tidak perlu beginPath()!

CARA 2 — Path (untuk garis, lingkaran, segitiga):
  SET strokeStyle atau fillStyle = warna
  beginPath()     ← mulai path baru (WAJIB!)
  moveTo(x1, y1)  ← pindah pena ke awal
  lineTo(x2, y2)  ← tarik garis ke tujuan
  arc(cx, cy, r, 0, 2*PI)  ← atau buat busur
  closePath()     ← tutup path (opsional)
  fill()          ← isi dengan warna
  stroke()        ← atau gambar garis
💻 Kode — Perbandingan (state-based.js)
// Cara 1: Rectangle (langsung)
stateCtx.fillStyle = "#3b82f6";
stateCtx.fillRect(80, 90, 170, 105);

// Cara 2: Path (garis merah)
stateCtx.beginPath();       // WAJIB!
stateCtx.moveTo(310, 110);
stateCtx.lineTo(500, 185);
stateCtx.strokeStyle = "#f43f5e";
stateCtx.lineWidth   = 4;
stateCtx.stroke();

// Cara 2: Path (lingkaran hijau)
stateCtx.beginPath();       // WAJIB!
stateCtx.arc(700, 135, 58,
             0, Math.PI*2);
stateCtx.fillStyle = "#22c55e";
stateCtx.fill();
💡 beginPath() WAJIB sebelum path baru. Tanpanya, path lama akan ikut tergambar dan menghasilkan bentuk yang tidak diinginkan.
⚠️
GOTCHA PENTING
CSS Pixel vs Canvas Pixel — Bug Paling Umum
Canvas punya dua ukuran berbeda: ukuran internal (dari atribut HTML) dan ukuran tampilan (dari CSS). Jika canvas di-scale oleh CSS, koordinat mouse dari event harus dikonversi agar tidak meleset dari target yang dituju.
📋 Pseudocode — Konversi Koordinat
MASALAH:
  Canvas asli = 960 x 600 piksel (atribut HTML)
  CSS membuat canvas tampil 480px di layar
  Event mouse → koordinat CSS (piksel layar)
  Menggambar → koordinat canvas (piksel canvas)
  → Perlu DIKONVERSI!

RUMUS:
  rect = posisi + ukuran canvas di layar

  canvasX = (clientX - rect.left)
            x (lebarCanvas / lebarLayar)

  canvasY = (clientY - rect.top)
            x (tinggiCanvas / tinggiLayar)

CONTOH:
  Canvas = 960px, tampil = 480px (skala 2x)
  Klik di layar X = 120
  canvasX = 120 x (960/480) = 240
💻 Kode (state-based.js — mousemove)
stateCanvas.addEventListener("mousemove", e => {
  // Posisi dan ukuran canvas di layar
  const r =
    stateCanvas.getBoundingClientRect();

  // Konversi CSS pixel → canvas pixel
  stateMouse.x =
    (e.clientX - r.left) * SW / r.width;
  stateMouse.y =
    (e.clientY - r.top)  * SH / r.height;

  // Tampilkan di panel sidebar
  sid("mouseText").textContent =
    `(${Math.round(stateMouse.x)},
       ${Math.round(stateMouse.y)})`;
});
💡 getBoundingClientRect() mengembalikan posisi dan ukuran elemen di layar. Pembagian SW / r.width adalah faktor skala konversi dari koordinat CSS ke koordinat canvas internal.

Minimal 3 jenis primitif harus digambar di canvas: Rectangle, Line, Circle, dan Triangle. Setiap bentuk punya cara menggambar yang berbeda menggunakan Canvas 2D API.

▬
PRIMITIF #1
Rectangle — Kotak / Persegi Panjang
Rectangle adalah bentuk paling dasar di Canvas. Satu fungsi fillRect(x, y, lebar, tinggi) langsung menggambar kotak berisi warna. Parameter (x,y) adalah sudut kiri atas kotak. Tidak perlu beginPath!
📋 Pseudocode
SET warna isian = biru (#3b82f6)

GAMBAR kotak persegi panjang:
  titik sudut kiri atas = (80, 90)
  lebar   = 170 piksel
  tinggi  = 105 piksel

  fillRect(80, 90, 170, 105)
           |   |   |     |
           x   y   lebar tinggi

→ Canvas langsung mengisi area dengan warna biru
→ Tidak perlu beginPath() untuk rectangle!
💻 Kode (state-based.js — stateDraw)
// Set warna isian terlebih dahulu
stateCtx.fillStyle = "#3b82f6";

// fillRect(x, y, lebar, tinggi)
stateCtx.fillRect(80, 90, 170, 105);

// Alternatif: kotak outline saja
stateCtx.strokeStyle = "#3b82f6";
stateCtx.lineWidth   = 2;
stateCtx.strokeRect(80, 90, 170, 105);

// Player: kotak oranye yang bisa bergerak
stateCtx.fillStyle = statePlayer.color;
stateCtx.fillRect(
  statePlayer.x, statePlayer.y,
  statePlayer.w, statePlayer.h
);
💡 fillRect = kotak berisi warna. strokeRect = kotak hanya outline/garis. clearRect = hapus area (jadikan transparan). Tidak perlu beginPath() untuk ketiganya!
╱
PRIMITIF #2
Line — Garis Lurus
Garis dibuat menggunakan path. Path adalah jalur tak terlihat yang kita definisikan, lalu Canvas menggambar garis mengikutinya. Urutan wajib: beginPath → moveTo → lineTo → stroke.
📋 Pseudocode
LANGKAH 1: Mulai path baru (hapus path lama)
  beginPath()

LANGKAH 2: Angkat pena ke titik awal
  moveTo(310, 110)
  x=310 dari kiri, y=110 dari atas
  (pena berpindah, tidak meninggalkan jejak)

LANGKAH 3: Turunkan pena, seret ke tujuan
  lineTo(500, 185)
  x=500, y=185
  (pena meninggalkan jejak path)

LANGKAH 4: Atur tampilan garis
  strokeStyle = merah (#f43f5e)
  lineWidth   = 4 piksel

LANGKAH 5: Cetak garis mengikuti path
  stroke()
  → Garis merah dari (310,110) ke (500,185)
💻 Kode (state-based.js — stateDraw)
// Langkah 1: Mulai path baru
stateCtx.beginPath();

// Langkah 2: Pindah pena ke titik awal
stateCtx.moveTo(310, 110);

// Langkah 3: Seret pena ke titik tujuan
stateCtx.lineTo(500, 185);

// Langkah 4: Set tampilan garis
stateCtx.strokeStyle = "#f43f5e";
stateCtx.lineWidth   = 4;

// Langkah 5: Cetak garis!
stateCtx.stroke();
💡 Analogi: moveTo = angkat pena dan pindah (tidak menggambar). lineTo = tekan pena dan seret ke posisi baru (meninggalkan jejak). stroke() = cetak semua jejak jadi garis nyata di canvas.
⬤
PRIMITIF #3
Circle — Lingkaran
Lingkaran dibuat dengan fungsi arc() yang artinya "busur". Dengan sudut 0 hingga 2π (= 360 derajat), terbentuklah lingkaran penuh. Parameter: titik pusat (cx, cy), radius (r), sudut awal dan akhir.
📋 Pseudocode
LANGKAH 1: Mulai path → beginPath()

LANGKAH 2: Buat busur lingkaran
  arc(cx, cy, r, sudutAwal, sudutAkhir)
  arc(700, 135, 58, 0, 2*PI)
       |    |   |   |    |
      cx   cy   r  0 deg  360 deg

  2*PI radian = 360 derajat = lingkaran penuh

LANGKAH 3: Isi dengan warna
  fillStyle = "#22c55e" (hijau)
  fill()

Referensi sudut radian:
  0     = posisi kanan   (arah jam 3)
  PI/2  = posisi bawah   (arah jam 6)
  PI    = posisi kiri    (arah jam 9)
  3PI/2 = posisi atas    (arah jam 12)
  2PI   = penuh (balik ke kanan)
💻 Kode (state-based.js — stateDraw)
// Lingkaran hijau statis
stateCtx.beginPath();
stateCtx.arc(
  700, 135,       // pusat (cx, cy)
  58,              // radius
  0, Math.PI * 2  // 0 sampai 360deg
);
stateCtx.fillStyle = "#22c55e";
stateCtx.fill();

// Bola bergerak dengan efek glow
stateCtx.beginPath();
stateCtx.arc(
  stateBall.x, stateBall.y, stateBall.r,
  0, Math.PI * 2
);
stateCtx.fillStyle   = stateBall.color;
stateCtx.shadowBlur  = 25;
stateCtx.shadowColor = stateBall.color;
stateCtx.fill();
stateCtx.shadowBlur  = 0;
💡 Math.PI = 3.14159... = 180 derajat. Jadi Math.PI * 2 = 360 derajat. Dalam pemrograman grafis, sudut dihitung dalam satuan radian, bukan derajat biasa.
▲
PRIMITIF #4
Triangle — Segitiga
Canvas tidak punya fungsi segitiga bawaan. Kita buat sendiri menggunakan path: hubungkan 3 titik sudut dengan garis, lalu tutup path agar sisi ketiga terbentuk otomatis. Teknik ini bisa dipakai untuk membuat poligon apapun.
📋 Pseudocode
3 titik sudut segitiga kita:
  Puncak (atas)      = (130, 360)
  Sudut kiri bawah   = (65, 490)
  Sudut kanan bawah  = (195, 490)

LANGKAH 1: Mulai path → beginPath()

LANGKAH 2: Pindah ke puncak
  moveTo(130, 360)

LANGKAH 3: Garis ke sudut kiri bawah
  lineTo(65, 490)

LANGKAH 4: Garis ke sudut kanan bawah
  lineTo(195, 490)

LANGKAH 5: TUTUP path → closePath()
  Canvas otomatis tarik garis dari (195,490)
  kembali ke moveTo pertama (130,360)
  → Segitiga tertutup sempurna!

LANGKAH 6: Isi → fillStyle + fill()
💻 Kode (state-based.js & event-based.js)
// Segitiga oranye
stateCtx.beginPath();

stateCtx.moveTo(130, 360); // puncak
stateCtx.lineTo(65,  490); // kiri bawah
stateCtx.lineTo(195, 490); // kanan bawah

// closePath: tarik garis ke moveTo pertama
stateCtx.closePath();

stateCtx.fillStyle = "#f97316";
stateCtx.fill();

// Bisa juga hanya outline:
// stateCtx.strokeStyle = "#f97316";
// stateCtx.stroke();
💡 closePath() menarik garis dari titik terakhir kembali ke moveTo pertama. Ini yang membuat segitiga tertutup rapat. Tanpa closePath(), sisi ketiga segitiga akan terbuka.

Warna di Canvas bisa berupa solid, transparan, palet berganti, hingga efek shadow glow. Di praktikum ini warna dikelola via array palet dengan indeks berputar menggunakan operator modulo.

🎨
WARNA #1
fillStyle dan strokeStyle — Cara Set Warna
fillStyle mengatur warna isian, strokeStyle mengatur warna garis/outline. Nilai bisa berupa hex (#rrggbb), RGB, RGBA (dengan transparansi), atau nama warna CSS. Warna berlaku sampai diubah lagi.
📋 Pseudocode — Format Warna
Format warna yang diterima Canvas:
  Hex         → "#8b5cf6"             (ungu)
  Hex pendek  → "#f00"                (merah)
  RGB         → "rgb(34, 211, 238)"
  RGBA        → "rgba(7, 17, 31, 0.13)"
              ↑ 0.13 = 13% opak (87% transparan)
  Nama CSS    → "red", "blue", "green"

ATURAN PENTING:
  Warna berlaku untuk SEMUA gambar setelah diset
  sampai diubah lagi!

  SET fillStyle = merah
  GAMBAR A   ← pakai merah
  GAMBAR B   ← masih merah!
  SET fillStyle = biru
  GAMBAR C   ← baru pakai biru
💻 Kode (state-based.js — stateDraw)
// Kotak biru: hex color
stateCtx.fillStyle = "#3b82f6";
stateCtx.fillRect(80, 90, 170, 105);

// Garis merah: hex color
stateCtx.strokeStyle = "#f43f5e";

// Latar semi-transparan (trail effect)
// rgba(r, g, b, alpha)
stateCtx.fillStyle =
  "rgba(7, 17, 31, 0.13)";
// 0.13 = 13% opak = gambar lama memudar
stateCtx.fillRect(0, 0, SW, SH);

// Teks warna cyan di HUD
stateCtx.fillStyle = "#22d3ee";
stateCtx.fillText("Mouse: ...", 18, 575);
💡 RGBA: nilai ke-4 (alpha) dari 0 (transparan total) sampai 1 (penuh opak). Alpha 0.13 (13%) cocok untuk trail effect karena gambar lama memudar perlahan, tidak hilang sepenuhnya.
🌈
WARNA #2
Palet Warna — Array + Rotasi dengan Modulo
Semua warna disimpan dalam array palet. Sebuah indeks menunjuk warna aktif. Setiap klik, indeks bertambah. Operator modulo (%) memastikan indeks kembali ke 0 setelah melewati warna terakhir — berputar tanpa henti.
📋 Pseudocode
DEKLARASI:
  palet = [warna0, warna1, warna2, warna3, warna4]
    → 5 warna, indeks 0 sampai 4
  indeks = 0   ← mulai dari warna pertama

SAAT canvas diklik:
  indeks = (indeks + 1) MOD 5

Simulasi 6 klik berturut-turut:
  Awal  : 0 → "#8b5cf6" (ungu)
  Klik 1: (0+1)%5 = 1 → "#f43f5e" (merah)
  Klik 2: (1+1)%5 = 2 → "#22c55e" (hijau)
  Klik 3: (2+1)%5 = 3 → "#facc15" (kuning)
  Klik 4: (3+1)%5 = 4 → "#3b82f6" (biru)
  Klik 5: (4+1)%5 = 0 → "#8b5cf6" (ungu lagi!)
  → Berputar tanpa henti!
💻 Kode (state-based.js)
// Array palet 5 warna
const stateColors = [
  "#8b5cf6", // ungu
  "#f43f5e", // merah
  "#22c55e", // hijau
  "#facc15", // kuning
  "#3b82f6"  // biru
];
let stateColorIndex = 0;

// Saat canvas diklik
stateCanvas.addEventListener("click", () => {
  // Modulo: kembali ke 0 setelah indeks 4
  stateColorIndex =
    (stateColorIndex + 1) % stateColors.length;
  stateBall.color = stateColors[stateColorIndex];

  // Spawn lingkaran warna berbeda (+2)
  stateCircles.push({
    color: stateColors[
      (stateColorIndex+2) % stateColors.length
    ]
  });
});
💡 Operator % (modulo) = sisa bagi. 5 % 5 = 0. Teknik ini disebut circular indexing dan sangat umum dalam pemrograman game untuk membuat animasi atau pilihan yang berputar.
✨
WARNA #3
Shadow Glow — Efek Cahaya di Canvas
Canvas mendukung efek shadow yang bisa dipakai sebagai glow (cahaya). Dengan mengatur shadowColor sama dengan warna objek, objek terlihat bersinar. WAJIB reset shadowBlur = 0 setelah menggambar!
📋 Pseudocode
UNTUK EFEK GLOW:
  SET shadowBlur  = 25   ← radius cahaya
  SET shadowColor = warna_objek
  GAMBAR objek           ← otomatis bercahaya
  RESET shadowBlur = 0   ← WAJIB!

KENAPA HARUS DIRESET?
  Canvas bersifat "stateful": pengaturan berlaku
  sampai diubah. Tanpa reset:

  shadowBlur = 25
  Gambar bola (glow)
  Gambar kotak player ... (ikut glow!) ← BUG!

  Dengan reset:
  shadowBlur = 25
  Gambar bola (glow)
  shadowBlur = 0           ← matikan
  Gambar kotak player (normal) ← aman!
💻 Kode (state-based.js — stateDraw)
// Gambar bola dengan efek glow
stateCtx.beginPath();
stateCtx.arc(
  stateBall.x, stateBall.y, stateBall.r,
  0, Math.PI * 2
);
stateCtx.fillStyle   = stateBall.color;
stateCtx.shadowBlur  = 25;          // aktifkan
stateCtx.shadowColor = stateBall.color; // warna cahaya
stateCtx.fill();
stateCtx.shadowBlur  = 0;           // ← RESET!

// Gambar player (kotak + glow oranye)
stateCtx.fillStyle   = statePlayer.color;
stateCtx.shadowBlur  = 20;
stateCtx.shadowColor = statePlayer.color;
stateCtx.fillRect(
  statePlayer.x, statePlayer.y,
  statePlayer.w, statePlayer.h
);
stateCtx.shadowBlur  = 0;           // ← RESET!
💡 Jadikan kebiasaan: setiap shadowBlur = N selalu diikuti shadowBlur = 0 setelah menggambar. Ini mencegah bug visual yang sulit didiagnosis karena efeknya menyebar ke semua objek berikutnya.

Animasi Canvas bekerja dengan siklus hapus → update → gambar yang diulang ~60x per detik menggunakan requestAnimationFrame. Inilah yang disebut game loop.

🔄
ANIMASI #1
requestAnimationFrame — Mesin Animasi Canvas
requestAnimationFrame(fn) meminta browser memanggil fungsi fn pada frame layar berikutnya (~60x/detik). Dengan memanggil dirinya sendiri di akhir fungsi, terciptalah loop animasi yang berjalan terus.
📋 Pseudocode — Game Loop
FUNGSI stateFrame():
  JIKA tidak pause:

    LANGKAH 1 — BERSIHKAN canvas
      Hapus semua gambar dari frame sebelumnya

    LANGKAH 2 — UPDATE posisi
      Perbarui posisi bola, player, semua objek

    LANGKAH 3 — GAMBAR ulang
      Render semua objek di posisi baru

    frameCount += 1   ← hitung frame

  DAFTARKAN ke frame berikutnya:
  → requestAnimationFrame(stateFrame)

MULAI: requestAnimationFrame(stateFrame)

Timeline yang terjadi:
  Mulai → stateFrame → frame 1 selesai
           → stateFrame → frame 2 selesai
           → stateFrame → frame 3 selesai
           → ... (terus sampai dihentikan)
💻 Kode (state-based.js)
function stateFrame() {
  if (!statePaused) {
    stateClear();   // Langkah 1: hapus
    stateUpdate();  // Langkah 2: update
    stateDraw();    // Langkah 3: gambar
    stateFrames++;
    sid("frameText").textContent
      = stateFrames;
  }
  // Jadwalkan frame berikutnya
  requestAnimationFrame(stateFrame);
}

// Gambar frame pertama, lalu mulai loop
stateDraw();
requestAnimationFrame(stateFrame);
💡 requestAnimationFrame lebih baik dari setInterval: (1) sinkron dengan refresh rate layar, (2) otomatis berhenti saat tab tidak aktif — hemat baterai laptop, (3) animasi lebih halus dan konsisten.
🧹
ANIMASI #2
Clear Canvas — Normal vs Trail Effect
Sebelum frame baru, canvas perlu dibersihkan. Ada dua cara: clearRect (hapus total, animasi bersih) atau fillRect semi-transparan (hapus sebagian) yang menciptakan efek trail / jejak bercahaya.
📋 Pseudocode — Dua Mode Hapus
MODE NORMAL (trail = OFF):
  clearRect(0, 0, lebar, tinggi)
  → Hapus canvas sepenuhnya, frame baru bersih

MODE TRAIL (trail = ON):
  fillStyle = "rgba(7, 17, 31, 0.13)"  ← 13% gelap
  fillRect(0, 0, lebar, tinggi)
  → Gambar penutup gelap semi-transparan
  → Gambar lama memudar, tidak hilang total

SIMULASI TRAIL (bola bergerak):
  Frame 1: bola di x=100 (warna 100%)
  Frame 2: overlay 13% → gambar lama 87%
  Frame 3: overlay lagi → gambar lama 76%
  Frame 10: gambar lama ~25% tersisa
  → Terlihat seperti ekor yang memudar!
💻 Kode (state-based.js — stateClear)
function stateClear() {
  if (!stateTrail) {
    // Mode normal: hapus total
    stateCtx.clearRect(0, 0, SW, SH);
  } else {
    // Mode trail: overlay semi-transparan
    stateCtx.fillStyle =
      "rgba(7,17,31,.13)";
    stateCtx.fillRect(0, 0, SW, SH);
  }
}

// Checkbox di panel mengontrol mode trail
sid("trail").onchange =
  e => stateTrail = e.target.checked;
💡 Alpha 0.13 (13%) dipilih agar ekor terlihat cukup panjang dan indah. Semakin kecil alpha, semakin lama ekor tersisa. Coba aktifkan "Trail Effect" di panel State-Based untuk melihat perbedaannya!
⚽
ANIMASI #3
Satu Objek Bergerak — Bola dengan Velocity
Bola bergerak dengan menambahkan kecepatan (velocity) ke posisi setiap frame. Bola punya vx (horizontal) dan vy (vertikal). Positif = kanan/bawah, negatif = kiri/atas. Saat menyentuh tepi, kecepatan dibalik.
📋 Pseudocode — Bola Bergerak
DEKLARASI bola:
  ball = {
    x:  420,   ← posisi horizontal
    y:  270,   ← posisi vertikal
    r:  25,    ← radius (jari-jari)
    vx: 3,     ← kecepatan horizontal (kanan)
    vy: 2.5    ← kecepatan vertikal (bawah)
  }

SETIAP frame (dalam stateUpdate):
  1. GERAKKAN bola:
     ball.x = ball.x + ball.vx
     ball.y = ball.y + ball.vy

  2. CEK dan PANTULKAN:
     JIKA ball.x menyentuh kiri atau kanan:
       ball.vx = -ball.vx   ← balik arah!
     JIKA ball.y menyentuh atas atau bawah:
       ball.vy = -ball.vy   ← balik arah!

MENGAPA CEK DENGAN RADIUS?
  Bola = lingkaran, pusatnya di (ball.x, ball.y)
  Tepi kiri bola = ball.x - ball.r
  Saat tepi kiri = 0, maka ball.x = ball.r
💻 Kode (state-based.js — stateUpdate)
function stateUpdate() {
  stateUpdatePlayer(); // update player juga

  // Gerakkan bola sesuai kecepatan
  stateBall.x += stateBall.vx;
  stateBall.y += stateBall.vy;

  // Pantulkan di batas kiri/kanan canvas
  if (stateBall.x < stateBall.r ||
      stateBall.x > SW - stateBall.r)
    stateBall.vx *= -1; // balik arah!

  // Pantulkan di batas atas/bawah canvas
  if (stateBall.y < stateBall.r ||
      stateBall.y > SH - stateBall.r)
    stateBall.vy *= -1; // balik arah!
}
💡 *= -1 adalah cara ringkas membalik tanda: vx = +3 → vx = -3 (ke kiri). vx = -3 → vx = +3 (ke kanan). Setara dengan vx = vx * -1 atau vx = -vx.

Interaksi pengguna diimplementasikan via event listener. Dua pendekatan: State-Based (tombol dicek setiap frame → gerakan mulus) dan Event-Based (gerak saat event → diskrit).

stateCanvas.addEventListener(

INTERAKSI #2
Keyboard State-Based — Gerakan Mulus Setiap Frame
Simpan status tombol (ditekan/dilepas) ke objek stateKeys. Setiap frame, cek statusnya. Jika tombol masih ditekan, player terus bergerak. Hasilnya: gerakan sangat mulus — berbeda dengan event-based yang diskrit.
📋 Pseudocode — State-Based Keyboard
DEKLARASI stateKeys = {}   ← objek kosong

EVENT keydown:
  stateKeys["ArrowLeft"] = true   ← tandai ditekan
  stateKeys["a"]         = true   ← versi huruf kecil

EVENT keyup:
  stateKeys["ArrowLeft"] = false  ← tandai dilepas
  stateKeys["a"]         = false

FUNGSI updatePlayer() dipanggil SETIAP FRAME:
  speed = nilai dari slider kecepatan

  JIKA stateKeys["ArrowLeft"] ATAU stateKeys["a"]:
    player.x -= speed        ← gerak kiri
  JIKA stateKeys["ArrowRight"] ATAU stateKeys["d"]:
    player.x += speed        ← gerak kanan
  JIKA stateKeys["ArrowUp"] ATAU stateKeys["w"]:
    player.y -= speed        ← gerak atas
  JIKA stateKeys["ArrowDown"] ATAU stateKeys["s"]:
    player.y += speed        ← gerak bawah

  CLAMP player → jangan boleh keluar canvas
💻 Kode (state-based.js)
const stateKeys = {};
const sclamp =
  (v,a,b) => Math.max(a, Math.min(b, v));

window.addEventListener("keydown", e => {
  stateKeys[e.key]               = true;
  stateKeys[e.key.toLowerCase()] = true;
});
window.addEventListener("keyup", e => {
  stateKeys[e.key]               = false;
  stateKeys[e.key.toLowerCase()] = false;
});

function stateUpdatePlayer() {
  const s = Number(sid("speed").value);
  if(stateKeys.ArrowLeft ||stateKeys.a)
    statePlayer.x -= s;
  if(stateKeys.ArrowRight||stateKeys.d)
    statePlayer.x += s;
  if(stateKeys.ArrowUp   ||stateKeys.w)
    statePlayer.y -= s;
  if(stateKeys.ArrowDown ||stateKeys.s)
    statePlayer.y += s;
  statePlayer.x =
    sclamp(statePlayer.x, 0, SW-statePlayer.w);
  statePlayer.y =
    sclamp(statePlayer.y, 0, SH-statePlayer.h);
}
💡 Kenapa simpan dua versi (e.key dan lowercase)? "ArrowLeft" ≠ "arrowleft". Menyimpan keduanya memastikan pengecekan stateKeys.a bekerja untuk huruf besar dan kecil.

INTERAKSI #3
Keyboard Event-Based — Gerakan Diskrit per Keydown
Player langsung bergerak saat event keydown terjadi — tidak ada cek per-frame. Hasilnya: gerakan melompat-lompat (diskrit). Cocok untuk game RPG atau UI berbasis keyboard. Gerakan terasa “patah-patah” dibanding state-based.
📋 Pseudocode — Event-Based
PERBANDINGAN:
  State-Based: cek tombol SETIAP FRAME
    → gerakan MULUS (smooth)
  Event-Based: gerak SAAT EVENT keydown
    → gerakan DISKRIT (patah-patah)

EVENT keydown:
  eventCount += 1
  UPDATE counter di panel

  key = event.key.toLowerCase()
  speed = player.speed  (= 5)

  JIKA ArrowRight ATAU "d": player.x += speed
  JIKA ArrowLeft  ATAU "a": player.x -= speed
  JIKA ArrowUp    ATAU "w": player.y -= speed
  JIKA ArrowDown  ATAU "s": player.y += speed

  CLAMP player dalam batas canvas
  UPDATE tampilan tombol di panel
💻 Kode (event-based.js)
window.addEventListener("keydown", e => {
  eventCount++;
  eid("eventText").textContent =
    `${eventCount} keydown`;

  const k = e.key.toLowerCase();
  const s = eventPlayer.speed; // = 5

  if(e.key==="ArrowRight"||k==="d")
    eventPlayer.x += s;
  if(e.key==="ArrowLeft" ||k==="a")
    eventPlayer.x -= s;
  if(e.key==="ArrowUp"   ||k==="w")
    eventPlayer.y -= s;
  if(e.key==="ArrowDown" ||k==="s")
    eventPlayer.y += s;

  eventPlayer.x = Math.max(0, Math.min(
    EW - eventPlayer.w, eventPlayer.x));
  eventPlayer.y = Math.max(0, Math.min(
    EH - eventPlayer.h, eventPlayer.y));
  eid("eventKeysText").textContent = e.key;
});
💡 Math.max(0, Math.min(max, nilai)) adalah implementasi clamp: nilai tidak kurang dari 0 dan tidak lebih dari max. Ini mencegah player menembus batas canvas.

CHALLENGE #1
Objek Memantul di Batas Canvas
Pantulan disimulasikan dengan membalik tanda kecepatan (*= -1) saat objek menyentuh tepi canvas. Pengecekan menggunakan radius agar tepi lingkaran (bukan pusatnya) yang menyentuh dinding.
📋 Pseudocode
INISIALISASI:
  ball.vx = +3    ← bergerak ke kanan
  ball.vy = +2.5  ← bergerak ke bawah

SETIAP frame:
  GERAK:
    ball.x += ball.vx
    ball.y += ball.vy

  CEK batas kiri (ball.x - r < 0):
    JIKA ball.x < ball.r:
      ball.vx = -ball.vx   ← balik ke kanan

  CEK batas kanan (ball.x + r > lebarCanvas):
    JIKA ball.x > lebarCanvas - ball.r:
      ball.vx = -ball.vx   ← balik ke kiri

  CEK batas atas dan bawah: sama, tapi ball.vy

CONTOH pembalikan:
  ball.vx = +3  → menyentuh kanan
  ball.vx = -3  ← sekarang bergerak ke kiri
  ball.vx = -3  → menyentuh kiri
  ball.vx = +3  ← bergerak ke kanan lagi!
💻 Kode (state-based.js & event-based.js)
// Dalam stateUpdate():
stateBall.x += stateBall.vx;
stateBall.y += stateBall.vy;

// Pantulan kiri-kanan
if (stateBall.x < stateBall.r ||
    stateBall.x > SW - stateBall.r)
  stateBall.vx *= -1;

// Pantulan atas-bawah
if (stateBall.y < stateBall.r ||
    stateBall.y > SH - stateBall.r)
  stateBall.vy *= -1;

// Event-based.js: persis sama
eventBall.x += eventBall.vx;
eventBall.y += eventBall.vy;
if(eventBall.x<eventBall.r||
   eventBall.x>EW-eventBall.r)
  eventBall.vx*=-1;
if(eventBall.y<eventBall.r||
   eventBall.y>EH-eventBall.r)
  eventBall.vy*=-1;
💡 Kenapa ball.x < ball.r (bukan 0)? Karena bola adalah lingkaran dengan pusat di ball.x. Tepi kiri bola = ball.x - ball.r. Agar tepi kiri = 0, berarti ball.x harus = ball.r.

CHALLENGE #3
Warna Berubah Saat Diklik + Spawn Lingkaran
Klik canvas melakukan dua hal sekaligus: (1) rotasi warna bola menggunakan modulo, (2) menambahkan lingkaran baru ke array di posisi klik. Lingkaran tersimpan permanen dalam array dan digambar ulang setiap frame.
📋 Pseudocode
PERSIAPAN:
  palet = [warna0, warna1, warna2, warna3, warna4]
  indeks = 0
  circles = []   ← array kosong

SAAT canvas diklik:
  AKSI 1: Rotasi warna bola
    indeks = (indeks + 1) MOD 5
    ball.warna = palet[indeks]

  AKSI 2: Spawn lingkaran di posisi klik
    warnaBaru = palet[(indeks + 2) MOD 5]
    circles.push({
      x: mouse.x, y: mouse.y,
      r: 14, warna: warnaBaru
    })

SETIAP frame dalam draw():
  UNTUK setiap c dalam circles[]:
    GAMBAR lingkaran di (c.x, c.y)

SAAT tombol Clear ditekan:
  circles.length = 0   ← kosongkan array
💻 Kode (state-based.js)
const stateCircles = [];

stateCanvas.addEventListener("click", () => {
  // Rotasi warna bola
  stateColorIndex =
    (stateColorIndex+1) % stateColors.length;
  stateBall.color = stateColors[stateColorIndex];

  // Spawn lingkaran warna berbeda
  stateCircles.push({
    x: stateMouse.x, y: stateMouse.y, r: 14,
    color: stateColors[
      (stateColorIndex+2)%stateColors.length
    ]
  });

// Dalam stateDraw():

CHALLENGE #4
Objek Digerakkan Keyboard + Fungsi Clamp
Player digerakkan WASD / Arrow Keys. Fungsi clamp memastikan player tidak keluar canvas. Clamp = “jepit” nilai agar selalu berada di antara minimum dan maksimum yang diizinkan.
📋 Pseudocode — Keyboard + Clamp
FUNGSI clamp(nilai, min, max):
  JIKA nilai < min: kembalikan min
  JIKA nilai > max: kembalikan max
  SELAIN ITU:       kembalikan nilai

CONTOH:
  clamp(-10, 0, 960) = 0    ← dipatok ke 0
  clamp(500, 0, 960) = 500  ← dalam rentang
  clamp(999, 0, 960) = 960  ← dipatok ke 960

SETELAH player bergerak (WASD/Arrow):
  player.x = clamp(player.x,
               0,                   ← batas kiri
               lebarCanvas - lebarPlayer)  ← batas kanan

  player.y = clamp(player.y,
               0,                    ← batas atas
               tinggiCanvas - tinggiPlayer) ← batas bawah

KENAPA (lebar - lebarPlayer)?
  Canvas lebar = 960, player lebar = 52
  Max player.x = 960 - 52 = 908
  → Player tidak bisa keluar dari kanan!
💻 Kode (state-based.js)
// Clamp: satu baris, tiga operasi
const sclamp =
  (v, a, b) => Math.max(a, Math.min(b, v));

function stateUpdatePlayer() {
  const s = Number(sid("speed").value);

  if(stateKeys.ArrowLeft ||stateKeys.a)
    statePlayer.x -= s;
  if(stateKeys.ArrowRight||stateKeys.d)
    statePlayer.x += s;
  if(stateKeys.ArrowUp   ||stateKeys.w)
    statePlayer.y -= s;
  if(stateKeys.ArrowDown ||stateKeys.s)
    statePlayer.y += s;

  // Clamp: player tidak boleh keluar canvas
  statePlayer.x = sclamp(
    statePlayer.x, 0, SW - statePlayer.w);
  statePlayer.y = sclamp(
    statePlayer.y, 0, SH - statePlayer.h);
}
💡 Math.max(a, Math.min(b, v)): Math.min(b, v) = tidak lebih dari max. Math.max(a, ...) = tidak kurang dari min. Dua operasi proteksi dalam satu baris yang elegan!
