Minimal 3 jenis primitif digambar di canvas: Rectangle, Line, Circle, dan Triangle.

RECTANGLE
Kotak / Persegi Panjang
📋 Pseudocode
SET warna isi = "#3b82f6"
GAMBAR kotak pada (80, 90)
  lebar = 170, tinggi = 105
💻 Kode (state-based.js)
ctx.fillStyle = "#3b82f6";
ctx.fillRect(80, 90, 170, 105);

Fungsi fillRect(x, y, w, h) menggambar kotak berisi warna tanpa outline.

LINE
Garis
📋 Pseudocode
MULAI path baru
PINDAH ke titik (310, 110)
TARIK garis ke (500, 185)
SET warna garis = "#f43f5e"
SET tebal garis = 4
GAMBAR garis
💻 Kode (state-based.js)
ctx.beginPath();
ctx.moveTo(310, 110);
ctx.lineTo(500, 185);
ctx.strokeStyle = "#f43f5e";
ctx.lineWidth   = 4;
ctx.stroke();

beginPath() memulai jalur baru; moveTo + lineTo mendefinisikan garis; stroke() menggambarnya.

CIRCLE
Lingkaran
📋 Pseudocode
MULAI path baru
GAMBAR busur di pusat (700, 135)
  radius = 58
  sudut  = 0 sampai 2π (lingkaran penuh)
SET warna isi = "#22c55e"
ISI lingkaran
💻 Kode (state-based.js)
ctx.beginPath();
ctx.arc(700, 135, 58,
        0, Math.PI * 2);
ctx.fillStyle = "#22c55e";
ctx.fill();

arc(cx, cy, r, startAngle, endAngle) — sudut 2π berarti lingkaran penuh (360°).

TRIANGLE
Segitiga

MULAI path baru
PINDAH ke puncak    (130, 360)
TARIK garis ke kiri bawah (65, 490)
TARIK garis ke kanan bawah (195, 490)
TUTUP path (kembali ke puncak)

ctx.beginPath();

closePath() menarik garis otomatis ke titik awal sehingga segitiga tertutup.

Animasi dibuat dengan loop requestAnimationFrame. Setiap frame: clear → update → draw.
🔄
GAME LOOP
requestAnimationFrame — Siklus Animasi
📋 Pseudocode
FUNGSI stateFrame():
  JIKA tidak pause:
    BERSIHKAN canvas          ← hapus frame lama
    UPDATE semua posisi objek ← hitung posisi baru
    GAMBAR semua objek        ← render ke canvas
    frameCount += 1
  DAFTARKAN stateFrame sebagai callback frame berikutnya

PANGGIL stateFrame() ← memulai loop
💻 Kode (state-based.js)
function stateFrame() {
  if (!statePaused) {
    stateClear();   // hapus / trail
    stateUpdate();  // perbarui posisi
    stateDraw();    // gambar ulang
    stateFrames++;
  }
  requestAnimationFrame(stateFrame);
}

requestAnimationFrame(stateFrame); // mulai!

SATU OBJEK BERGERAK
Bola Memantul di Batas Canvas
📋 Pseudocode
ball = { x:420, y:270, vx:3, vy:2.5, r:25 }

SETIAP frame:
  ball.x += ball.vx
  ball.y += ball.vy

  JIKA ball.x < radius ATAU ball.x > lebar - radius:
    ball.vx = -ball.vx   ← balik arah horizontal

  JIKA ball.y < radius ATAU ball.y > tinggi - radius:
    ball.vy = -ball.vy   ← balik arah vertikal
💻 Kode (state-based.js)
stateBall.x += stateBall.vx;
stateBall.y += stateBall.vy;

if (stateBall.x < stateBall.r ||
    stateBall.x > SW - stateBall.r)
  stateBall.vx *= -1;

if (stateBall.y < stateBall.r ||
    stateBall.y > SH - stateBall.r)
  stateBall.vy *= -1;
💫
TRAIL EFFECT
Efek Jejak (State-Based)
📋 Pseudocode
JIKA trail AKTIF:
  GAMBAR persegi panjang semi-transparan
  ← mengaburkan frame lama (bukan menghapus)
JIKA trail NONAKTIF:
  HAPUS canvas sepenuhnya
💻 Kode (state-based.js)
function stateClear() {
  if (!stateTrail) {
    ctx.clearRect(0,0, SW, SH);
  } else {
    ctx.fillStyle = "rgba(7,17,31,.13)";
    ctx.fillRect(0, 0, SW, SH);
  }
}

Alpha 0.13 (13%) mengaburkan perlahan, menghasilkan efek ekor / trail pada objek bergerak.

Dua jenis interaksi diterapkan: mouse (koordinat, klik) dan keyboard (WASD / Arrow).
🖱️
MOUSE KOORDINAT
Menampilkan Posisi Mouse
📋 Pseudocode
SAAT mousemove di canvas:
  rect = posisi canvas di layar
  mouse.x = (clientX - rect.kiri) * (lebarCanvas / lebarRect)
  mouse.y = (clientY - rect.atas) * (tinggiCanvas / tinggiRect)
  TAMPILKAN koordinat di HUD dan panel
💻 Kode (state-based.js)
canvas.addEventListener("mousemove", e => {
  const r = canvas.getBoundingClientRect();
  mouse.x = (e.clientX - r.left)
            * SW / r.width;
  mouse.y = (e.clientY - r.top)
            * SH / r.height;
});

Perkalian SW/r.width mengkonversi koordinat CSS ke koordinat canvas asli.

⌨️
KEYBOARD STATE-BASED
State Keyboard (Smooth Movement)
📋 Pseudocode
keys = {}  ← objek state tombol

SAAT keydown:  keys[tombol] = true
SAAT keyup:    keys[tombol] = false

SETIAP frame:
  JIKA keys[ArrowLeft] ATAU keys[a]: player.x -= speed
  JIKA keys[ArrowRight] ATAU keys[d]: player.x += speed
  JIKA keys[ArrowUp] ATAU keys[w]: player.y -= speed
  JIKA keys[ArrowDown] ATAU keys[s]: player.y += speed
💻 Kode (state-based.js)
const stateKeys = {};

window.addEventListener("keydown", e => {
  stateKeys[e.key] = true;
});
window.addEventListener("keyup", e => {
  stateKeys[e.key] = false;
});

// Dipakai setiap frame:
if (stateKeys.ArrowLeft || stateKeys.a)
  player.x -= speed;
⚡
KEYBOARD EVENT-BASED
Gerakan Per-Event (Discrete)
📋 Pseudocode
SAAT keydown terjadi:
  eventCount += 1
  JIKA tombol = ArrowRight ATAU "d": player.x += speed
  JIKA tombol = ArrowLeft  ATAU "a": player.x -= speed
  JIKA tombol = ArrowUp    ATAU "w": player.y -= speed
  JIKA tombol = ArrowDown  ATAU "s": player.y += speed
  BATASI player dalam batas canvas
💻 Kode (event-based.js)
window.addEventListener("keydown", e => {
  const k = e.key.toLowerCase();
  if (e.key === "ArrowRight" || k==="d")
    player.x += speed;
  if (e.key === "ArrowLeft"  || k==="a")
    player.x -= speed;
  player.x = Math.max(0,
    Math.min(EW - player.w, player.x));
});

Perbedaan utama: State-based = mulus (dicek tiap frame). Event-based = diskrit (hanya saat tombol ditekan).

CHALLENGE #2
Objek Digerakkan Keyboard + Clamp
📋 Pseudocode
FUNGSI clamp(nilai, min, max):
  KEMBALIKAN MAX(min, MIN(max, nilai))

FUNGSI updatePlayer():
  speed = nilai slider
  JIKA ArrowLeft ATAU a ditekan: player.x -= speed
  JIKA ArrowRight ATAU d ditekan: player.x += speed
  JIKA ArrowUp ATAU w ditekan: player.y -= speed
  JIKA ArrowDown ATAU s ditekan: player.y += speed
  player.x = clamp(player.x, 0, lebarCanvas - lebar)
  player.y = clamp(player.y, 0, tinggiCanvas - tinggi)
💻 Kode (state-based.js)
const sclamp = (v,a,b) =>
  Math.max(a, Math.min(b, v));

function stateUpdatePlayer() {
  const s = +speedSlider.value;
  if(stateKeys.ArrowLeft||stateKeys.a)
    player.x -= s;
  if(stateKeys.ArrowRight||stateKeys.d)
    player.x += s;
  player.x = sclamp(player.x,
    0, SW - player.w);
  player.y = sclamp(player.y,
    0, SH - player.h);
}

Menampilkan Koordinat Mouse Real-Time
📋 Pseudocode
SAAT mousemove di canvas:
  Hitung (x, y) relatif terhadap canvas
  TAMPILKAN di panel sidebar → "Mouse: (x, y)"
  GAMBAR di HUD canvas (pojok kiri bawah)

// 1. Update variabel saat mouse bergerak
canvas.addEventListener("mousemove", e => {
  const r = canvas.getBoundingClientRect();
  mouse.x = (e.clientX - r.left) * SW / r.width;
  mouse.y = (e.clientY - r.top) * SH / r.height;
  // Update panel
  mouseText.textContent =
    `(${Math.round(mouse.x)}, ${Math.round(mouse.y)})`;
});

// 2. Gambar di HUD canvas (dalam stateDraw)

CHALLENGE #5
Objek Mengikuti Mouse (Mouse Tracker)
📋 Pseudocode
SAAT mousemove di canvas:
  Simpan posisi mouse → mouse.x, mouse.y

SETIAP frame (dalam stateDraw):
  GAMBAR lingkaran outline di (mouse.x, mouse.y)
    radius = 18, warna = "#22d3ee"

← Karena stateDraw dipanggil tiap frame,
  lingkaran selalu muncul di posisi mouse terbaru
  → efeknya: MENGIKUTI mouse secara real-time
💻 Kode (state-based.js — stateDraw)
// Variabel posisi mouse (diupdate saat mousemove)
const stateMouse = { x: 0, y: 0 };

// Event: simpan posisi setiap mouse bergerak
canvas.addEventListener("mousemove", e => {
  const r = canvas.getBoundingClientRect();
  stateMouse.x = (e.clientX - r.left) * SW / r.width;
  stateMouse.y = (e.clientY - r.top)  * SH / r.height;

// Dalam stateDraw() — digambar SETIAP FRAME:
ctx.beginPath();
ctx.arc(stateMouse.x, stateMouse.y,

HTML Canvas adalah elemen HTML yang menyediakan area gambar berbasis piksel.
Semua rendering dilakukan via JavaScript menggunakan Canvas 2D API.
📦
ELEMEN HTML
Tag <canvas> dan Atributnya
📋 Penjelasan
- <canvas> hanyalah WADAH kosong (tidak menggambar sendiri)
- Atribut width & height = ukuran canvas dalam PIKSEL
  (bukan ukuran CSS — hati-hati bedakan!)
- Isi dikendalikan 100% oleh JavaScript
- Tanpa JS → canvas hanya kotak transparan
💻 Kode HTML
<!-- Deklarasi canvas di HTML -->
<canvas
  id="graphicsCanvas"
  width=960
  height=600>
  Teks fallback (browser lama)
</canvas>

// Ambil referensi di JavaScript
const canvas = document.getElementById("graphicsCanvas");
const ctx    = canvas.getContext("2d"); // konteks 2D

getContext("2d") mengembalikan objek CanvasRenderingContext2D — ini yang dipakai untuk semua operasi menggambar.

📐
SISTEM KOORDINAT
Asal (0,0) di Pojok Kiri Atas
📋 Penjelasan
Sistem koordinat Canvas 2D:

  (0,0) ──────────────→  X bertambah ke KANAN
    │   ·  ·  ·  ·
    │   ·  ·  ·  ·
    │   ·  ·  ·  ·
    ↓
  Y bertambah ke BAWAH

Contoh:
  (0,0)   = pojok kiri atas
  (960,0) = pojok kanan atas
  (0,600) = pojok kiri bawah
  (480,300) = tengah canvas 960×600
💻 Contoh Koordinat
// Titik di tengah canvas 960×600
const cx = canvas.width  / 2; // = 480
const cy = canvas.height / 2; // = 300

// Gambar titik merah di tengah

ctx.fillRect(cx - 5, cy - 5, 10, 10);

SIKLUS RENDER
Cara Animasi Bekerja di Canvas
📋 Alur Animasi Canvas
┌─────────────────────────────────────────────┐
│  requestAnimationFrame(loop)                │
│                                             │
│  SETIAP FRAME (~60x per detik):             │
│    1. clearRect() atau fillRect transparan  │  ← hapus frame lama
│    2. Update posisi semua objek             │  ← logika gerak
│    3. Gambar ulang semua objek              │  ← render baru
│    4. requestAnimationFrame(loop) lagi      │  ← jadwalkan frame berikutnya
└─────────────────────────────────────────────┘

Kenapa requestAnimationFrame?
→ Sinkron dengan refresh rate layar (60/120 Hz)
→ Otomatis berhenti saat tab tidak aktif (hemat baterai)
→ Lebih halus dari setInterval()
💻 Template Animasi Canvas
const canvas = document.getElementById("myCanvas");
const ctx    = canvas.getContext("2d");

let x = 100;          // posisi bola
let vx = 3;          // kecepatan

function loop() {
  // 1. Hapus canvas
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // 2. Update
  x += vx;
  if (x > canvas.width) x = 0; // wrap around

  // 3. Gambar
  ctx.fillStyle = "#8b5cf6";
  ctx.beginPath();
  ctx.arc(x, 100, 20, 0, Math.PI*2);
  ctx.fill();

  // 4. Jadwalkan frame berikutnya
  requestAnimationFrame(loop);
}

requestAnimationFrame(loop); // mulai!
⚠️
GOTCHA PENTING
CSS Pixel vs Canvas Pixel
📋 Masalah Umum
Canvas berukuran 960×600 piksel (atribut HTML)
tapi ditampilkan dengan CSS: width: 100%

→ CSS men-SCALE canvas ke ukuran berbeda
→ Koordinat mouse dari event pakai CSS pixel
→ Harus DIKONVERSI ke canvas pixel!

Rumus konversi:
  canvasX = (mouseClientX - rect.left) * (canvasWidth  / rect.width)
  canvasY = (mouseClientY - rect.top)  * (canvasHeight / rect.height)
💻 Kode Konversi (dipakai di state-based.js)
canvas.addEventListener("mousemove", e => {
  const rect = canvas.getBoundingClientRect();

  // Koordinat mouse dalam CANVAS PIKSEL (bukan CSS)
  mouse.x = (e.clientX - rect.left)
            * canvas.width  / rect.width;
  mouse.y = (e.clientY - rect.top)
            * canvas.height / rect.height;
});

Tanpa konversi ini, klik/mouse akan meleset jika canvas di-scale oleh CSS. Ini salah satu bug paling umum saat belajar Canvas!
