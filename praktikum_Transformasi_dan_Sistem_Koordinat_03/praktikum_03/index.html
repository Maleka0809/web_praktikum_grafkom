WebGL Interactive Transform

Eksplorasi grafika komputer: Model Matrix, TRS vs RTS, Parent-Child, & Orbit

Penjelasan Implementasi WebGL2 & Tantangan

🎯 Penjelasan Konsep Utama

1. WebGL2 & Shader

Mengambil konteks rendering WebGL2 dan mengkompilasi GLSL ES 3.00 shader. Vertex shader menerima koordinat dan mengalikannya dengan uModelMatrix 3x3 untuk transformasi titik pada bidang 2D. gl_Position diatur ke vec4(pos.xy, 0.0, 1.0).

vec3 pos = uModelMatrix * vec3(aPosition, 1.0);

2. Geometry & VAO

Menggunakan VAO (Vertex Array Object) yang diwajibkan di WebGL2. VAO menyimpan state ikatan data seperti ARRAY_BUFFER dan vertexAttribPointer sehingga kita hanya perlu memanggil gl.bindVertexArray(vao) sebelum memanggil fungsi draw.

const squareBuffer = gl.createBuffer();
const vaoSquare = gl.createVertexArray();
gl.bindVertexArray(vaoSquare);
gl.bindBuffer(gl.ARRAY_BUFFER, squareBuffer);
gl.bufferData(gl.ARRAY_BUFFER, squareVertices, gl.STATIC_DRAW);
gl.vertexAttribPointer(aPosition, 2, gl.FLOAT, false, 0, 0);
gl.enableVertexAttribArray(aPosition);

3. Matriks Transformasi (TRS / RTS)

Translasi, rotasi, dan skala masing-masing diwakili matriks 3x3 homogen. Urutan perkalian matriks (TRS: Translasi × Rotasi × Skala) memastikan objek diskala, diputar di tempat, lalu dipindah posisinya. Mode RTS memutar objek mengitari origin dunia.

function getMatrix(x, y, r, sx, sy, isTRS) {
  let t = [1, 0, 0, 0, 1, 0, x, y, 1];
  let c = Math.cos(r), s = Math.sin(r);
  let rot = [c, s, 0, -s, c, 0, 0, 0, 1];
  let sc = [sx, 0, 0, 0, sy, 0, 0, 0, 1];
  let mat;
  if (isTRS) { // Mode TRS
    mat = multiply3x3(rot, sc);
    mat = multiply3x3(t, mat);
  } else {     // Mode RTS
    mat = multiply3x3(t, sc);
    mat = multiply3x3(rot, mat);
  }
  return mat;
}

4. Hierarki Parent-Child

Objek B adalah Child dari Objek A. Posisi lokal Objek B bergantung dari posisi A. Dengan matB = matA * matB_local, seluruh transformasi dari Objek A akan diturunkan secara hierarkis ke Objek B.

let matA = getMatrix(objA.x, objA.y, objA.r, objA.sx, objA.sy, orderTRS);
let matB_local = getMatrix(objB.x, objB.y, objB.r, objB.sx, objB.sy, orderTRS);

let matB;
if (chkParent.checked) {
  matB = multiply3x3(matA, matB_local);
} else {
  matB = matB_local;
}

5. Kesimpulan

Praktikum ini mendemonstrasikan implementasi Hierarchical Transform menggunakan WebGL2. Penerapan konsep scene graph ditunjukkan melalui objek Parent (Putih) dan Child (Kuning). Selain itu, urutan transformasi matriks (TRS vs RTS) terbukti menghasilkan output visual yang sangat berbeda karena sifat non-komutatif dari matriks. Seluruh perhitungan matriks dikerjakan di CPU menggunakan array 1D homogen dan dikirim ke GPU sebagai uniform mat3.

// Rendering Objek B dengan uniform matB
gl.uniformMatrix3fv(uModelMatrix, false, new Float32Array(matB));
gl.uniform4fv(uColor, objB.color);
gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);

🚀 Penjelasan Tantangan (Challenges A - F)

Konsep Dasar: Parent dan Child

Dalam sistem hierarki, sebuah Child akan mewarisi transformasi dari Parent-nya. Setiap objek memiliki matriks lokalnya sendiri. Untuk mendapatkan posisi aktual (World Matrix) dari sebuah child, kita mengalikan matriks dunia milik parent dengan matriks lokal milik child tersebut.

Contoh: Jika badan mobil (Parent) bergerak maju, maka roda (Child) akan secara otomatis ikut terbawa maju tanpa harus memprogram pergerakan roda satu per satu.

// Implementasi kalkulasi posisi Child di render loop
let matB_local = getMatrix(objB.x, objB.y, objB.r, objB.sx, objB.sy, orderTRS);

if (chkParent.checked) {
    // ChildWorld = ParentWorld × ChildLocal
    // matA adalah world matrix dari Parent (Objek Putih)
    matB = multiply3x3(matA, matB_local); 
} else {
    // Jika tidak terhubung, gunakan posisinya sendiri
    matB = matB_local;
}

Challenge A: Reset Transform

Fitur ini digunakan untuk mengembalikan semua objek ke state awal mereka secara instan. Ketika tombol R pada keyboard ditekan, posisi (x, y), rotasi (r), dan skala (sx, sy) diatur kembali ke nilai default.

Implementasi di Canvas:
Coba gerakkan Objek Putih (Parent) dengan tombol WASD, lalu putar dengan Q/E, dan ubah skalanya. Setelah posisinya acak-acakan, tekan tombol R di keyboard atau klik tombol Reset (R) pada panel interaksi. Secara instan, Objek Putih akan melompat kembali ke posisi kiri, dan Objek Kuning kembali berpusat memutari Objek Putih dengan nilai yang disetel ulang persis ke kondisi awal ketika halaman dimuat.

// Event listener keyboard untuk Challenge A
if (e.key.toLowerCase() === 'r') {
    // Reset objek A (Parent)
    objA = { x: -0.38, y: 0.0, r: 0.0, sx: 1.0, sy: 1.0, color: [1.0, 1.0, 1.0, 1.0] };
    // Reset objek B (Child)
    objB = { x: 0.4, y: 0.0, r: 0.0, sx: 0.5, sy: 0.5, color: [0.98, 0.82, 0.28, 1.0] };
    // Reset rotasi orbit
    objC.r = 0;
}

Challenge B: Transform Preset

Menggunakan tombol 1, 2, dan 3 untuk memanggil tiga konfigurasi (preset) transformasi yang berbeda pada objek utama secara cepat.

Implementasi di Canvas:
Tekan tombol 1 di keyboard untuk memindahkan Objek Putih ke posisi atas-kiri tanpa rotasi secara instan.
Tekan tombol 2 untuk memindahkan Objek Putih ke titik tengah (Origin), memutarnya sejauh 45°, dan memperbesar ukurannya secara seragam (Uniform Scale).
Tekan tombol 3 untuk memindahkannya ke bawah-kanan, merotasinya sejauh 90°, dan mengubah bentuknya menjadi pipih secara asimetris (Non-uniform scale).

// Event listener keyboard untuk Challenge B
if (e.key === '1') {
    // Preset 1: Pindah posisi saja
    objA = { x: -0.4, y: 0.2, r: 0.0, sx: 1.0, sy: 1.0, color: objA.color };
} else if (e.key === '2') {
    // Preset 2: Rotasi 45 derajat dan perbesar ukuran (Uniform)
    objA = { x: 0.0, y: 0.0, r: 45 * Math.PI / 180, sx: 1.5, sy: 1.5, color: objA.color };
} else if (e.key === '3') {
    // Preset 3: Rotasi 90 derajat dan skala non-uniform (gepeng)
    objA = { x: 0.3, y: -0.2, r: 90 * Math.PI / 180, sx: 1.8, sy: 0.6, color: objA.color };
}

Challenge C: Toggle Transform Order

Menekan tombol T akan mengubah urutan operasi transformasi matriks. Hal ini sangat penting karena perkalian matriks bersifat tidak komutatif (A × B ≠ B × A). Pada orde T × R × S, objek berputar di tempatnya sendiri. Pada orde R × T × S, objek akan mengorbit terhadap titik Origin (0,0).

Implementasi di Canvas:
Pertama, geser Objek Putih menjauhi titik tengah (garis silang putih sumbu) pakai tombol WASD. Secara default, matriks beroperasi dengan orde TRS, jadi jika Anda menekan Q atau E, Objek Putih berputar di porosnya sendiri (titik hijau).
Sekarang, tekan tombol T (atau klik tombol Order: RTS). Jika Anda menekan rotasi Q/E sekarang, Objek Putih tidak lagi berputar di porosnya, melainkan terlempar melingkar dan berputar jauh mengelilingi Origin (titik 0,0 kanvas) bagaikan bulan yang mengelilingi orbit bumi sebesar radius dari pusat tersebut.

// Di fungsi pembuatan matriks getMatrix()
let mat;
if (isTRS) {
    // T x R x S (Scale duluan, Rotasi di tempat, lalu Translasi)
    mat = multiply3x3(rot, sc);
    mat = multiply3x3(t, mat);
} else {
    // R x T x S (Scale duluan, Translasi sejauh jarak, lalu Rotasi mengitari Origin)
    mat = multiply3x3(t, sc);
    mat = multiply3x3(rot, mat);
}

Challenge D: Mouse Translation

Klik dan geser pada area canvas untuk memindahkan objek utama ke posisi kursor. Pixel mouse dari koordinat layar diubah (mapping) menjadi ruang Normalised Device Coordinates (NDC) yang berjarak dari -1 hingga 1.

Implementasi di Canvas:
Arahkan kursor Anda bebas di area kanvas layar hitam. Klik dan tahan tombol kiri mouse (Drag), lalu geser mouse Anda. Objek Putih beserta anakannya (Objek Kuning) akan melompat dan melekat (snap) menempel tepat pada posisi kursor Anda. Selama mouse digeser, posisi objek akan terus diperbarui secara real-time mengikuti pergerakan kursor Anda.

// Event Listener pada element Canvas
canvas.addEventListener('mousemove', (e) => {
    if (!isDragging) return; // Hanya jalan jika mouse ditekan (klik)
    
    // Dapatkan batas canvas
    const rect = canvas.getBoundingClientRect();
    
    // Konversi Mouse Pixel ke koordinat NDC WebGL (-1.0 s/d 1.0)
    const x = ((e.clientX - rect.left) / rect.width) * 2.0 - 1.0;
    const y = -(((e.clientY - rect.top) / rect.height) * 2.0 - 1.0); // Y terbalik
    
    // Terapkan ke Translation Matrix (Update posisi objek A)
    objA.x = x;
    objA.y = y;
});

Challenge E: Parent & Child

Objek Child (B) memiliki status lokasinya (x=0.4, y=0.0) yang diukur dari titik tengah Parent, bukan dari tengah layar. Ketika Parent (A) digeser dengan tombol WASD atau dirotasi, objek B akan mengikuti gerakan tersebut karena matriksnya terikat bersama Parent.

Implementasi di Canvas:
Perhatikan bahwa Objek Kuning terikat pada Objek Putih. Coba geser Objek Putih ke atas dengan menekan tombol W; perhatikan bahwa Objek Kuning ikut terseret bersama secara otomatis tanpa harus diberi perintah gerak tambahan. Coba putar Objek Putih menggunakan E; Objek Kuning pun akan ikut memutar menyesuaikan orientasi hadap objek Parent-nya (terbawa arus putaran rotasi objek Putih). Fitur rantai matriks (Hierarchy) ini bisa dihentikan sementara dengan menghilangkan centang pada kotak "Parent-Child Aktif", yang akan membuat Objek Kuning diam dan berpisah secara independen.

// Objek B terdefinisi sebagai independen, koordinat X 0.4 diukur dari Origin lokal
let objB = { x: 0.4, y: 0.0, r: 0.0, sx: 0.5, sy: 0.5, color: [0.98, 0.82, 0.28, 1.0] };

// Namun saat di-render, matriksnya mewarisi transformasi matA (Parent-nya)
let matA = getMatrix(objA.x, objA.y, objA.r, objA.sx, objA.sy, orderTRS);
let matB_local = getMatrix(objB.x, objB.y, objB.r, objB.sx, objB.sy, orderTRS);

let matB;
if (chkParent.checked) {
    // Matriks Parent × Matriks Lokal = Ruang Dunia Child
    matB = multiply3x3(matA, matB_local); 
} else {
    matB = matB_local; // Bergerak tanpa terpengaruh posisi Parent
}

Challenge F: Simple Orbit

Dengan menerapkan Matrix Composition, kita memprogram agar objek B secara konstan menambahkan nilai sudut rotasinya terhadap Parent, sehingga mensimulasikan gerakan mengorbit yang mulus berbasis waktu (Delta Time).

Implementasi di Canvas:
Karena opsi "Auto Animasi (Obj B & C)" dihidupkan, script memberikan perintah rotasi secara konstan. Namun, karena Objek Kuning terikat dan bergantung sebagai Child pada matriks dari Objek Putih (seperti pada Challenge E), perputaran konstan tersebut tersimulasikan sebagai perputaran orbit mengelilingi pusat Objek Putih bagaikan satelit, tanpa perlu rumus trigonometri tambahan. Coba tekan tombol Balik Orbit B (O) untuk melihat orbit berbalik arah.

// Menjalankan orbit otomatis di render loop
if (chkAutoB.checked) {
    // objB terus menambahkan sudut putarannya perlahan mengikuti detak waktu.
    // Karena ia terikat dengan objA lewat Matriks Parent, rotasinya mengorbit Parent!
    objB.r += rSpd * dt * orbitDirection; 
}
