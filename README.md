# Website Praktikum Grafika Komputer A

Website praktikum interaktif menggunakan HTML, CSS, dan JavaScript tanpa React.

## Struktur
- `index.html` — halaman Home
- `halaman_awal/halaman_praktikum.html` — daftar praktikum
- `halaman_awal/kontak_kami.html` — informasi anggota
- `halaman_awal/praktikum1.html` — Interactive Canvas
- `halaman_awal/praktikum.css` — styling utama
- `halaman_awal/state-based.js` — implementasi State-Based terpisah
- `halaman_awal/event-based.js` — implementasi Event-Based terpisah

## Cara Menjalankan
Buka `index.html` di browser. Untuk hasil terbaik gunakan VS Code + Live Server.

## Kontrol Praktikum 1
### State-Based
- W/A/S/D atau Arrow: menggerakkan player
- P: Pause/Resume
- R: Reset
- C: ganti warna bola
- Klik Canvas: membuat lingkaran
- Speed: mengatur kecepatan
- Trail Effect: efek jejak

### Event-Based
- W/A/S/D atau Arrow: menggerakkan player melalui event keyboard
- P: Pause/Resume
- R: Reset
- C: ganti warna bola
- Klik Canvas: membuat lingkaran

State-Based dan Event-Based berada pada file JavaScript yang berbeda dan tidak digabungkan.
